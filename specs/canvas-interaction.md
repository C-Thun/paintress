# 画布交互：多画板 + 平移缩放

- 状态：待评审（2026-11-10）
- 起因：operator 有大量复杂 `.pen` 文件（多顶层画板、尺寸远超视口），当前 iframe 只能原样展示左上角，无法导航。
- 目标：让查看器具备「画布」而非「图片」的浏览能力。

## 一、现状与差距

| 能力 | 现状 | 差距 |
| --- | --- | --- |
| 渲染 | 所有顶层节点已按 `x/y` 绝对定位在 `.ptr-canvas` 内 | 无 |
| 视口 | iframe 固定尺寸，内容溢出被裁 | 无缩放/平移 |
| 多画板 | 渲染结果里就在，但只能看到落在视口内的部分 | 无画板列表/聚焦 |
| 选中高亮 | 已有（`data-ptr-selected`） | 缩放后需保证命中精度 |

关键认知：**渲染器不需要改画布本身**，所有顶层节点已经在正确坐标上。缺的是「视口变换」与「画板导航」两层 UI。

## 二、方案

### 1. 视口变换（zoom / pan）

在 iframe 内对 `.ptr-canvas` 施加 CSS transform（同源可直接操作 contentDocument）：

```text
.ptr-canvas {
  transform-origin: 0 0;
  transform: translate(tx px, ty px) scale(z);
}
```

- **为什么用 transform 而不是改 iframe 尺寸**：`transform` 走合成层，不触发重排；改尺寸会让 iframe 重新布局并重新解析整棵树，大文档明显卡顿。
- **为什么在 iframe 内变换而不是缩放 iframe 元素**：缩放 iframe 元素会让内部内容位图化（模糊），且命中坐标需要额外换算。

交互：

| 操作 | 行为 |
| --- | --- |
| 滚轮 | 以鼠标位置为锚点缩放（Figma 式），范围 0.1–4 |
| 空格 + 拖拽 / 中键拖拽 | 平移 |
| 拖拽空白区 | 平移（无修饰键时的默认） |
| `Ctrl/Cmd + 0` | 缩放到 100% |
| `Shift + 1` | 适应窗口（fit） |

状态：`zoom` / `tx` / `ty` 存前端 signal，按 `项目+文件` 写入 `localStorage`，重开保持。

### 2. 多画板导航

渲染器为每个**顶层节点**补充几何元数据，前端无需解析 CSS：

```html
<div data-node-id="board-a" data-board="1" data-board-name="首页"
     data-board-x="0" data-board-y="0" data-board-w="1440" data-board-h="900" ...>
```

- `data-board="1"` 标记顶层（画布直属子节点）
- 其余四项给出包围盒数值，供导航与 fit 计算

前端：

- **画板条**（顶部或侧栏）：列出所有画板，显示名称与尺寸；点击 → 平滑平移+缩放到该画板
- **全部**：fit 整个画布
- 画板数 ≤ 1 时隐藏该条（避免单画板文件出现无意义 UI）

### 3. 与已有能力的配合

| 已有能力 | 缩放/平移后需要处理 |
| --- | --- |
| 点击选中 | 命中检测基于 DOM，变换后浏览器自动处理，无需改 |
| 面包屑 | 不受影响 |
| 变更高亮 | 不受影响（属性驱动） |
| 短号标记 | 不变；但「聚焦短号」需把目标画板滚入视口 |

### 4. 边界与风险

| 风险 | 处理 |
| --- | --- |
| 超大画布（如 20000×20000）fit 后 zoom 极小 | 设下限 0.02；提示「已缩至最小」 |
| 高 DPI 下 transform 文字发虚 | 只在 zoom > 1 时保持矢量（浏览器默认行为），不额外处理 |
| 拖拽与点击冲突 | 位移 < 3px 视为点击，否则视为拖拽 |
| 多次 transform 叠加 | 统一由单一 `applyViewport()` 重写，不做增量累加 |
| 画板名重复/缺失 | 回退显示 `#id` |

## 三、实施顺序

| 步 | 内容 | 验证 |
| --- | --- | --- |
| 1 | 渲染器输出 `data-board*` 元数据 | 渲染 HTML 断言；已有快照测试扩展 |
| 2 | 视口控制器（zoom/pan/fit，无 UI 按钮） | 单测：坐标换算（锚点缩放不漂移） |
| 3 | 画板条与聚焦 | 多画板 fixture 实测 |
| 4 | 快捷键与 localStorage 持久化 | 手测 + 刷新保持 |
| 5 | 与短号聚焦联动 | 点击标记 → 目标画板进入视口 |

## 四、不做的事

- **不做拖拽改布局**：本工具只读设计稿，不提供编辑器能力（`AGENTS.md#核心决策 4`）。
- **不做无限画布滚动条**：用平移代替，避免与 iframe 滚动条冲突。
- **不做多文件并排**：一次看一个文件；并排属于后续议题。
