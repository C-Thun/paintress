# format/ — 设计稿格式规格

本目录存放 paintress 对设计稿格式的**自有表述**。它是格式的唯一事实来源（single source of truth）。

## 文件

| 文件 | 内容 |
| --- | --- |
| `spec.yaml` | 字段字典：共享标量、枚举、文档结构、节点类型、样式与布局块、ptr 扩展 |

## 分层结构

```text
format/spec.yaml      事实层：字段、类型、枚举、默认值（机器可读）
        ↓ 派生（不手工维护第二份）
src/schema/           可执行层：Zod 校验（未来实现）
        ↓ 生成
docs/                 人读层：心智模型与示例（未来实现）
```

规则：**改动先进 `spec.yaml`，再派生代码**。任何层与 `spec.yaml` 不一致，以 `spec.yaml` 为准。

## 双格式策略（摘要）

- **`.ptr` 是 paintress 的标准文件格式**；`.pen` 是兼容格式（读、编辑、渲染完全一致）。
- `.pen` 层：`pen_profile` 段，**冻结**。只按既有规格解析，永不修改。
- `.ptr` 层：`ptr` 段，**演进**。版本升级、字段扩展、兼容承诺都在这层。
- 新建文档一律产出 `.ptr`；`.pen` 仅在调用方显式指定时写入。
- 完整决策与理由：`.agents/memory/ARCHITECTURE.md#D-006`

## 事实来源与红线

- 事实（字段名、类型、枚举取值、默认值）来自 2026-11-10 对本地 schema 文本的观察与真实文件抽样比对；溯源记录见 `specs/pen-format-licensing.md`。
- **只记录功能性事实，不含任何源文档的表述文本。** 描述均为本项目自写。
- 来源未覆盖或未验证的点显式标记：
  - `TBD`：缺证据，待实测补充
  - `unverified`：有证据但顺序/语义未确认

## 标记约定

- `enum_ref`：指向 `enums` 段的同名枚举，避免重复列表
- `one_of`：多形态字段的分支
- `evidence`：该事实的出处说明
- `note` / `known_gaps`：来源中的缺口与存疑点
