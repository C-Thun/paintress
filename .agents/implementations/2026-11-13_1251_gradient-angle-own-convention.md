# 2026-11-13T12:51+08:00 — 渐变角度改成自有约定（0 = 从左往右，正值顺时针），流光带恢复为竖向光带

Pencil 已退场，格式由 paintress 持有。渐变角度不再迁就旧稿的「0 指向上」，改成**与设计手感一致**的约定：

- `rotation` 0 = 从左往右（方向指向右），正值顺时针；
- `0 → 向右 / 90 → 向上 / 180 → 向左 / 270 → 向下`，CSS 角 = `90 - rotation`；
- `conic(angular)` 同此角度。

判据是「可见结果对不对」：整份稿子里唯一显眼的渐变是 `流光带`（透明 → `$fg-1` → 透明，从左往右飘），
只有 0=向右 才画得出**一条竖光带**；按 0=向上 会变成横跨整卡的白色色块（就是崔总最早截图指的那处）。
`Fade / 左段·右段底纹`、`ToolsBar 渐隐覆盖` 这些是「同色 ↔ 自身透明」，两条约定肉眼无差，不为它们保留旧约定。
