# 2026-11-13T01:58+08:00 — 第三方评审修正：高亮动画、活跃连接关停、版本自动提示与测试 flake

对首批六项做了第三方评审，实际读 diff、跑定向/全量测试并用 Chromium 与独立 daemon 复现。只修改本轮引入的代码与测试。

## 确认并修复

1. **高亮透明度循环实际未生效**：`ui/src/App.tsx` 注入的基线 `box-shadow` 带 `!important`，压过同属性关键帧；浏览器在 0/0.5/1/1.5s 读数完全相同。移除该 important，保留 2px，并把样式提取到 `ui/src/frame-style.ts` 作为唯一来源。新增 `test/viewer-style.spec.ts`，真实 Chromium 断言两次计算样式不同且均为 2px。
2. **有活跃连接时关停不退出**：`src/web/daemon.ts` 只调用 `server.close()`，agent attach 与设计稿 SSE 会使 Promise 一直等待。现在跟踪控制面 socket 并以 `end()` 结束（保留已排队响应），HTTP 在 `close()` 后调用 `closeAllConnections()`；关闭中不再新建自动退场定时器。`test/autodetach.spec.ts` 覆盖 agent、设计稿 SSE、项目列表 SSE 三类连接都关闭。
3. **关停连接数漏算查看器**：原统计不含项目列表 SSE，弹窗会显示 0。daemon 统一 `connectionCount()`（agent + 设计稿 SSE + 项目列表 SSE），`/api/projects`、`/api/shutdown` 与新增 `/api/version` 共用；弹窗打开时重新取实时值，文案改为「长连接」。实测打开设计稿后显示 2 条。
4. **版本探测结果不会自动出现**：首次 `/api/projects` 启动后台探测但返回旧值，前端此前没有后续请求。新增轻量 `GET /api/version`，前端 4s 后补取并每 60s 轮询；失败静默，且不因轮询扫描项目目录。浏览器路由模拟首次 null、随后 9.9.9，徽章自动出现。
5. **`shot --board` 缺值静默截整张**：`src/cli.ts` 明确拒绝 boolean 形态的 `--board`，`test/cli.spec.ts` 验证退出码 1 与错误文案。
6. **变更通知测试仍 flake**：根因有两层——非阻塞通知 Promise 未被测试等待，以及用例错误地比较 ids 数组长度。`ChangesStore` 的 1.5s 合并窗口后新记录会替换旧记录，长度可能从 2 变 1。`test/changes.spec.ts` 现在包装测试侧 sendRequest 以捕获真实通知 Promise（仅测试放宽到 10s，生产端仍 2s 非阻塞），再从磁盘找本次新生成的 id 并断言其被记录；轮询上限 10s、用例上限 15s。

另修正 `src/shared/version-compare.ts` 一处与实现不符的注释。
